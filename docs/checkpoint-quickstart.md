# TimeTransle 存读档 MVP

> 用户尚未进行验收与审阅，已有通过记录仅为代理自测。

1. 运行同目录 `TimeTransleController.exe`。
2. 点“选择 → 启动程序…”，选择 `TimeTransleCheckpointFixture32.exe`。
3. 暂停后点“保存”；继续运行，在测试窗口切到英文输入，按 N 进入 B 关。
4. 设置所需倍率并暂停，然后按 **反引号 + F9** 读取，恢复 A 关并保留当前倍率和暂停状态。
5. 点“继续”，方向键移动、空格加分；关闭测试窗口后存档槽清除。

保存快捷键为 **反引号 + F5**，读取也有工具栏按钮。一个内存槽，仅在同一进程内有效，不写存档文件。原有“选择已运行进程”仍可使用时间控制，检查点需从 Controller 启动。

代理自测只覆盖随附的 x86、D3D9、DirectSound 单线程测试程序。三款真实游戏、x64 存档、其他图形接口、文件回滚和退出后读取均未验证。当前源码按用户要求公开供审阅，第三方来源与许可记录保留。

结果和失败修复见 `checkpoint-acceptance.md`；来源和许可见 `notices/` 与 `NOTICE-THIRD-PARTY.md`。蓝/橙棋盘来自被改写的同一纹理；音乐实际 PCM 采样值 A=100、B=226，标题还显示逻辑状态、栈/静态帧数与声音位置。
